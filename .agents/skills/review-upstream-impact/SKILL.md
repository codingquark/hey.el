# Review upstream impact

Review changes in an upstream project and assess their implications for the
current project. Establish the relevant revisions, investigate affected
integration points, and distinguish necessary fixes from useful opportunities.
Support conclusions with source evidence and state verification limits.

Follow repository instructions and preserve existing work. A review request
does not itself authorize upgrades or implementation. Choose the investigation
and validation approach to suit the changes.

For this project, the upstream HEY CLI checkout is at `~/workspace/hey-cli`
(a sibling of this repository). Use it as the local source for comparison with
its upstream.
